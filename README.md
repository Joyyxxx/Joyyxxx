# XXtools

OmniToolbox 在线模块，提供移速与视距、地图图标传送、副本助手、战斗与日常功能。

在 OmniToolbox 的在线模块中添加本仓库地址，安装并启用 XXtools。需要 OmniToolbox 1.1.9.1 或更高版本，并匹配模块支持的客户端结构版本。

- `/xx`：打开主窗口。
- `/xxtp`：打开独立地图图标 TP 窗口。
- `/xxoff`：关闭全部功能。

其他命令见插件内“命令”页。开关命令不带参数时切换开启／关闭；移速和视距可直接附加数值。

日常采集联动需另外加载 GBR、MissFisher、vnavmesh；当前适配 GBR 7.5.0.5。
